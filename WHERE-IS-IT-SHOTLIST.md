# Where-is-it pictures: findings and shot list

Written 2026-11-20. Round 1 of adding "where is it" pictures to the manual. Only `getting-started/baked-first-workflow` is done; the shot list below is the plan for the other pages.

## Where the manual is read

- **The website is the real home**: `faxlab.github.io/spline-architect-docs` (Docusaurus, this repo). It already shows WebP stills and WebP/MP4 clips from `static/img/` (about 31 MB in total). New pictures go there as WebP with the `AnnotatedShot` component.
- **The plugin's `Content/Python/spline_architect_agent/docs/` is a text-only export of this site**, made by `Scripts/Agent/sync_agent_docs.py` in the plugin repo. The script turns every image into its alt text (`[Image: ...]`, `[Screenshot: ...]`), so the plugin copy never contains pictures and is overwritten on every sync. Editing pictures into the plugin copy would be lost at the next sync and would add to the Fab download for nothing. Nothing is added to the plugin download by this work.
- Inside the editor the manual is only read by AI agents (`read_doc` tool). Level designers reach the website through the Documentation entry in the SA menu.
- `SplineArchitectPackageContract.ps1` only requires that `docs\production\baking.md` exists in the package and rejects archive files (zip, 7z, ...). It has no rule about image files or sizes in this folder, because there are none.
- Picture rules used: stills as WebP quality 90, cropped to the panel that matters, under about 150 KB each (the four new ones are 5 to 7 KB each, 24 KB in total); clips 5 to 20 s, silent, under 3 MB, with a WebP poster.
