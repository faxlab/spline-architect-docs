# Spline Architect documentation

Docusaurus documentation in `docs/`; site configuration in `docusaurus.config.ts` and `sidebars.ts`.

Use `npm ci`, `npm run typecheck`, and `npm run build` to verify changes. Keep existing Pages URLs and redirects stable because shipped plugin builds link to them.

## Local workspace

Worktrees go under `C:\WT\spline-architect-docs\<branch>`, one per task, removed after merge. Build staging and throwaway hosts go under `C:\T`.
